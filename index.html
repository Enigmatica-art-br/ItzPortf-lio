I — O gesto

Design não é decoração.

É composição: peso, silêncio, contraste, ritmo e imagem. Cada trabalho pede uma forma própria — não uma moldura repetida.

Projetos em destaque

Uma seleção curta para leitura rápida. A exposição completa reúne todos os projetos e permite percorrê-los lateralmente.
